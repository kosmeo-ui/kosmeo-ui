Accessibility (Lighthouse/axe, both themes). New tokens --primary-color-text, --danger-color-text and --warning-color-contrast for text that must clear 4.5:1; secondary, dark-theme success and light-theme alert backgrounds darkened so white text passes; --text-color-link darkened. Opacity-faded text in EmptyState, AddressBlock and RecoveryCodeGrid now uses --text-color-secondary. New props: BorderedSection `as` (heading level), Checkbox and Dropdown `aria-label`, Button `aria-pressed`. Accessible names for loading Buttons, dropdown arrows, MultiSelect chips, RichTextEditor toolbar and editing area, and InfiniteScroll's icon buttons and row checkboxes. Date inputs link their labels; TagCard uses list items; Input addons are no longer aria-hidden; PhoneInput's country button name matches its visible text; the password toggle has a 24px target. .k-sr-only moves to the global stylesheet.
