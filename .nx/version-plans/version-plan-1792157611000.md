`ThemeProvider` lets an app set its own values for the theme tokens, light and dark, by typed camelCased name (`primaryColor` for `--k-primary-color`). A family color given without its hover and active shades gets them mixed from it. `--k-border-shadow-color-active` now follows `--k-primary-color` instead of a fixed color, so focus rings match a custom primary.
