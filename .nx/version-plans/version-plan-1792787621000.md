`TableCellLink` and `TableCellButton` give a clickable `Table`, `DataTable` or `InfiniteScroll` a keyboard- and screen-reader-reachable way to open a row: put one in the row's primary cell. `TableCellLink` is polymorphic (`as={Link} to="/users/1"`, or a plain `href`), so middle-click, open in new tab and copy link work too. Row click is now a mouse convenience that ignores clicks on any link, button or other control inside the row, so those no longer need `stopPropagation` or `disableRowClick`, and a router link in a cell no longer navigates twice. A control in a leading cell with `disableRowClick: false` no longer fires the row click; a click on the cell around it still does.
