`InfiniteScroll`'s title is now a heading, so screen readers' heading navigation finds it. It renders as an `<h2>` by default instead of a `<p>`, and `menu.titleAs` (`"h1" | "h2" | "h3" | "h4" | "p"`) picks the element: `"h1"` when the list is the page's main content, or `"p"` to keep the old markup. It looks the same at every level.
